# Rice Purity Test

An open-source, privacy-friendly Rice Purity Test built with HTML, CSS, and JavaScript.

## Features

- Interactive Rice Purity Test
- Instant score calculation
- Simple and mobile-friendly interface
- Runs directly in the browser
- No account required
- Easy to customize
- Lightweight HTML, CSS, and JavaScript

## Live Demo

Try the online version:

https://riicepuritytest.com

## How It Works

The Rice Purity Test consists of a series of questions about different life experiences. Users select the statements that apply to them, and the application calculates a score based on their answers.

The project is designed to provide a simple and accessible way to take the test online while keeping the implementation lightweight.
